# Code of conduct

Regeneration Lab adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, Discussions and every other project space.

In short: be welcoming to people from every background, including biologists new to code and developers new to biology. Criticise ideas, models and evidence, never people. Harassment, personal attacks and sharing private information are not tolerated.

## Reporting

Report conduct problems privately to the maintainer, [@aadilghani1](https://github.com/aadilghani1), through a direct message on GitHub, or open a [private security advisory](https://github.com/aadilghani1/regen-lab/security/advisories/new) marked "conduct". Reports are kept confidential. Enforcement follows the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
