# Can the termination module distinguish target length from completed regeneration?

Framed by Codex, 2026-11-23. In this model we predict that baseline and distal cuts reach the target length (within 5%), have nondecreasing positional identity along the nerve row, and exhaust the progenitor pool with no length increase in the final 50 steps. Reaching the target while growth continues should count as incomplete. Denervation, proximal excess, and disabled termination should retain their registered outcomes.

Run all five catalog scenarios at seeds 0–4. Sweep the baseline distal-growth threshold over 0.1, 0.2 (default), 0.4, and 2 model units with the same seeds. We predict the twofold changes preserve completion. The high threshold challenges that prediction beyond the local range. A single contrary run falsifies the corresponding prediction.
