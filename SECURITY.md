# Security policy

## Supported versions

Only the latest commit on `main` and the deployed viewer at https://aadilghani1.github.io/regen-lab/ are supported.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/aadilghani1/regen-lab/security/advisories/new). Please don't open a public issue. Expect an acknowledgement within 7 days.

In scope: the `regen` CLI, the research package (file handling, network calls to Europe PMC), the viewer, CI workflows and dependencies.

## Not security issues

Disagreements about biology, evidence or model behaviour belong in issues or Discussions. Content that falls outside the dry-lab scope of [CONSTITUTION.md](CONSTITUTION.md), Article I (wet-lab protocols, dosing, organism-level gene editing) should be reported privately through the same advisory form so it can be removed quickly.
